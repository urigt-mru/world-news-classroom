School-Ready Build Plan

  1. Auto-load episode: use a small server endpoint to call the YouTube Data API each morning and return the newest video ID.
  2. Student login: use Google, Microsoft, Clever, or school SSO.
  3. Save work: store submissions in Firebase, Supabase, PostgreSQL, or Google Sheets for a simple pilot.
  4. Weekly grading: teacher dashboard with score, feedback, missing-work flags, and CSV export.
  5. Optional: connect to Google Classroom after district approval.
